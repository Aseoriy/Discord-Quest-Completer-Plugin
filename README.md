# BetterDiscord and Vencord Quest Completer Plugin
a plugin i made for vencord (and betterdiscord now) to complete quests without having to watch the videos or play the games, i used aamiaa's quest completer code and just made it into a button. i put it in by downloading the vencord source code and addind the tsx file to src/plugins and making a new folder called questCompleter then placing in the tsx/ts file. you also must compile it and inject it to discord but new plugin yipee
